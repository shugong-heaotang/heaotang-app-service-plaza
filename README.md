# 和奥堂 APP 页面体系

本项目用于沉淀和奥堂 APP 的整体页面布局、核心入口和 UI 原型。

当前已定稿的核心页面是“服务广场”。后续首页、发现、我的等页面设计，均以服务广场确定的信息架构为基准继续展开。

## 当前定稿

- 底部主导航：首页 / 服务 / 发现 / 我的
- 当前页面：服务广场
- 顶部结构：标准商标 / 服务广场 / AI
- 三个核心服务：生命导航 / 俱乐部联盟 / 健康大管家
- 常用服务：活动广场 / 人脉中心 / 保障商城 / 二手集市 / AI / 学习广场
