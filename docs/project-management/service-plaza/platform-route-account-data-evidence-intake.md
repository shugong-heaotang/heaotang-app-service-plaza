## 六、回写规则

1. 证据字段完整后，先回写 `routing-and-temporary-page-spec.md` 或 `test-accounts-and-data.md`。
2. 再把对应 FE-PLAT 字段同步到 `platform-fact-submission-worksheet.md`。
3. 五项均具备真实证据位置后，才能填写 `fact-evidence-submission-packet.md` 的平台事实提交包。
4. 提交后由 `fact-evidence-intake-review.md` 判断待复核或退回补充。
5. 审计复核记录只能写入 `fact-evidence-review-run-log.md` 的 FR-PLAT，不得直接解除首次真实联调 No-Go。

## 七、当前禁止动作

1. 不把建议路由当作真实路由。
2. 不把 ADR 0003 当作临时页已实现证据。
3. 不记录真实密码、生产凭据或真实会员隐私。
4. 不把测试数据要求当作测试数据来源。
5. 不把返回路径要求当作返回路径已验证。
6. 不触发 FE-GATE、FE-ACC 或首次真实联调。
