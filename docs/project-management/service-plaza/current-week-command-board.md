## 可并行但不得越过门禁

- 生命导航、俱乐部联盟、健康大管家可以开始资料梳理、需求澄清、非目标和验收案例编写。
- 不得在需求冻结前扩写业务功能，不得把板块专属逻辑写入公共基础设施。
- 外部合作专项可以并行设计 OIDC/PKCE、域名白名单和合规清单，但未通过前不得把外部服务改为 active。

## 本周出口

只有以下条件全部满足，才允许进入三大板块业务并行开发：

1. L4-L5 门禁通过。
2. 每个板块的需求、非目标、数据责任和验收标准分别冻结。
3. 板块接入包通过自检和安全门禁。
4. 测试环境发布、回滚和 Handoff 路径可重复执行。

发现任何问题先关闭根因，再继续依赖它的下游工作。
