# 三大核心服务第一阶段主动作确认表

本文件用于把三大核心服务的第一阶段主动作收敛为“推荐默认项 + 板块 Agent 补齐确认”。未确认前，可以按推荐默认项准备材料，但不能据此解除首次真实联调 No-Go。

## 一、确认规则

1. 每个核心服务第一阶段只选择一个主动作。
2. 主动作必须形成用户提交、后台处理、状态反馈的最小闭环。
3. 主动作可以先在临时承接页中模拟，但必须能被正式页面替换。
4. 板块 Agent 可以修改推荐主动作，但必须同步影响范围和验收标准。
5. 平台 Agent 只按已确认或默认主动作准备联调占位，不视为完成。

## 三、推荐主链路

### 生命导航

```text
进入服务广场
点击生命导航
进入正式页面或临时承接页
点击提交导航申请
填写或模拟提交基础信息
后台记录申请
用户看到提交成功或待处理状态
```

### 俱乐部联盟

```text
进入服务广场
点击俱乐部联盟
进入正式页面或临时承接页
选择俱乐部分类
点击申请加入俱乐部
后台记录申请或进入审核
用户看到提交成功、审核中或待处理状态
```

### 健康大管家

```text
进入服务广场
点击健康大管家
进入正式页面或临时承接页
点击提交健康咨询
填写或模拟提交咨询内容
后台记录咨询
用户看到提交成功或待处理状态
```
