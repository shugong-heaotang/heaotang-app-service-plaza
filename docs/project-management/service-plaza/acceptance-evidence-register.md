# 服务广场验收证据登记表

本文件用于集中登记第一阶段验收所需证据。任何验收项没有证据，默认不能通过验收。

## 一、证据登记原则

1. 证据必须能证明一个具体验收项，不能只写“已确认”。
2. 截图、日志、路由、本地台账记录、Handoff、问题关闭结论都可以作为证据，但必须能追溯到补齐 Agent、确认时间和证据位置。
3. 真实账号密码不得写入本文件，只记录账号类型、保管方式和可用状态。
4. Partial Go 情况下，只登记已进入联调或验收的板块证据，未进入的板块标记为未适用或待补充。
5. 缺少主链路证据时，验收结论保持 No-Go，并回退到对应补证动作。

验收事实证据先按 `fact-evidence-submission-control-board.md` 的顺序提交到 `fact-evidence-intake-review.md` 的 FE-ACC-011 至 FE-ACC-013，再进入 `fact-evidence-review-run-log.md` 复核。未完成接收复核前，EV-011、EV-012、EV-013 不得从“待补充”改为“已形成”。

## 二、证据编号规则

1. 证据编号采用 `EV-三位数字`，在本文件内唯一，不因状态变化复用或改号。
2. 已登记编号只能更新状态、位置、摘要和回退动作；不得把待补证编号改写成已通过事实。
3. `phase-1-acceptance-checklist.md` 和 `phase-1-acceptance-run-record.md` 必须引用本文件编号；只有文件名、没有编号的引用视为待补证。
4. 一个证据可支撑多个验收项，但必须在摘要中写明覆盖范围；一个验收项也可引用多个证据编号。
5. 新增证据时按顺序追加编号，并保留“当前状态”为待补充、待复核、已形成、已失效之一。

## 六、缺证据回退规则

| 缺失证据 | 回退阶段 | 必须补齐 |
| --- | --- | --- |
| 缺 agent 分工或签核证据 | 确认和签核阶段 | agent 分工、主动作、平台条件确认 |
| 缺路由或页面访问证据 | 联调准备阶段 | 路由可访问、临时承接页可访问 |
| 缺主动作证据 | 板块联调阶段 | 主动作执行结果和状态反馈 |
| 缺权限、空状态、异常证据 | 平台联调阶段 | 账号、数据、异常处理验证 |
| 缺问题关闭证据 | 问题关闭阶段 | 关闭记录、延期原因、补齐 Agent |
| 缺 Handoff 证据 | Handoff 阶段 | 联调给测试交接记录和 Handoff 质量复核结论 |
| 缺验收执行证据 | 验收执行阶段 | 执行时间、范围、执行 Agent、结果、未通过项、回退动作 |
| 缺项目负责人裁决证据 | 裁决阶段 | 裁决依据、裁决人、裁决时间、是否允许进入下一阶段 |

## 七、验收引用方式

`phase-1-acceptance-checklist.md` 中每一条“证据”字段必须引用本文件的证据编号，或引用本文件登记的目标文件。没有引用证据编号的验收项，默认仍为待验收。
