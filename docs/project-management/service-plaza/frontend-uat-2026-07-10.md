## 六、结论与遗留项

正式前端工程基础门禁由 No-Go 更新为 **Partial Go**。页面、路由、状态恢复、构建、测试和隔离测试环境部署已经形成真实工程证据。

遗留项：

1. 三个主动作的真实 Go API 适配器已经完成，但尚无可安全使用的测试 JWT，未执行远程写入。
2. 测试服务器已确认三项写接口在无令牌时返回 401，越权边界通过。
3. 真实模式移动端登录面板已通过浏览器复核，不显示验证码或令牌，无横向溢出和控制台错误。
4. 正式前端已部署到测试服务器隔离目录，尚缺安全测试会话下的三项真实写入验收。

## 九、构建根因闭环

测试环境首次构建未带 `/app/service-plaza/` 公共路径。根因是历史生成的 `app/vite.config.js` 优先于 `vite.config.ts` 被 Vite 自动加载。已删除影子配置，将 Vite 与 Vitest 配置拆分，并在 `scripts/Build-ServicePlazaTestPackage.ps1` 增加重复配置失败门禁。修复后产物中文正常，JS/CSS 引用均带正确公共路径，11/11 测试通过。
