# 服务广场事实证据提交包

日期：2026-07-10

本文件是 `fact-evidence-intake-review.md` 的填写入口。提交包用于把事实证据从“待提交”推进到“待复核”。未填完整或不可验证的提交包不得进入门禁复核。

平台事实提交前，先用 `platform-fact-minimum-evidence-checklist.md` 补齐五项最小事实，再用 `platform-fact-submission-worksheet.md` 整理 FE-PLAT-001 至 FE-PLAT-005 字段，并按 `day-1-platform-submission-control-record.md` 做提交前控制；FE-PLAT-001 还必须按 `platform-fact-backfill-review-path.md` 满足环境、入口、三大核心服务路由或临时页、采用方案和证据位置要求。工作表未补齐时不得填写本提交包为待复核。

板块事实提交前，先用 `module-fact-submission-worksheet.md` 整理 FE-MOD-001 至 FE-MOD-003 字段；工作表未补齐时不得填写本提交包为待复核。

Handoff 事实提交前，先用 `handoff-fact-submission-worksheet.md` 整理 FE-HO-001 至 FE-HO-003 字段；工作表未补齐时不得填写本提交包为待复核。

## 一、提交原则

1. 每次提交必须填写接收编号、证据编号、P0-RUN、提交人、提交时间和证据位置。
2. 提交包只能记录事实字段；不得写“计划完成”“建议采用”“后续补齐”作为事实。
3. 测试账号只记录账号类型、环境、保管方式和可用状态；不得写真实密码、生产凭据或真实会员隐私。
4. 提交后状态只能进入“待复核”；是否变为“证据已形成，待门禁复核”由审计 Agent 按接收清单判断。
5. 退回补充时必须写明缺失字段、目标文件和下一步 Agent。
