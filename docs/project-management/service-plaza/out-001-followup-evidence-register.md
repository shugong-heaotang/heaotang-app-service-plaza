## 六、裁决触发规则

| 场景 | 是否裁决 | 裁决对象 |
| --- | --- | --- |
| 缺口已明确但当日未补齐 | 暂不裁决，先登记补齐检查 | 对应 Agent |
| T+1 后仍未补齐 | 是，进入 T+2 裁决准备 | 审计 Agent |
| T+2 后仍影响首次真实联调 | 是，项目负责人裁决 Partial Go 或继续 No-Go | 项目负责人 |
| 信息不完整但不影响当前门禁 | 暂不裁决，登记延期 | 对应 Agent |
| 涉及架构边界或范围变化 | 直接裁决，必要时形成 ADR | 项目负责人 / 规划 Agent |
