## 本轮关闭的问题

1. 后端动作权限错误继承业务 API scope：已分离导航 scope 与业务 scope，并加入运行时精确基线比较。
2. PowerShell 5 把 UTF-8 JSON 错解为乱码：精确比较改为直接按 UTF-8 原始字节读取。
3. PowerShell 5 丢失 4xx JSON 正文：错误读取优先使用 `ErrorDetails.Message`。
4. 部署后本地门禁失败不会自动回滚：部署脚本已增加激活后异常回滚流程；恢复演练仍需单独留证。
5. 生命导航达到日限额后无法重放：重放判定前置，限额计数与写入进入同一事务。
6. 俱乐部加入领域错误全部返回 400：不存在改为 404，非活跃/已是成员/容量冲突改为 409 并使用稳定机器码。
7. 俱乐部管理入口被标记 active 但业务管理尚未冻结：调整为 preview，权限通过后明确显示试用状态，不伪装业务功能完成。
8. 功能开关永久缓存导致已打开客户端无法响应配置变化：改为 60 秒到期刷新，读取失败继续安全关闭。
9. 回滚直接覆盖运行中二进制导致 PM2 短暂 `Permission denied`：改为临时恢复文件校验权限后同目录原子替换，并补充失败 stderr。
