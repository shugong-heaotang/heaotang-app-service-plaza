# 服务广场责任信息补齐模板

本模板用于补齐真实责任信息。当前项目先按项目负责人一人决策和 Agent 协同推进；如果后续出现真实平台或板块责任人，再把信息回写到 `owner-roster.md`。

## 一、补齐规则

1. 没有真实姓名或证据时，不虚构责任人。
2. 可以先登记 Agent 责任角色和待补齐项。
3. 补齐真实责任信息后，同步 `round-1-signoff-checklist.md`、`role-action-list.md` 和 `issue-pool.md`。
4. 最终验收责任未明确前，不进入第一阶段验收。

## 二、责任信息记录模板

```text
角色或板块：
当前承担方：项目负责人 / 平台 Agent / 板块 Agent / 验收 Agent / 真实责任人
真实姓名：
联系方式：
确认来源：
证据编号：
是否最终责任人：是 / 否 / 待补齐
可承担事项：
仍需补齐：
```
