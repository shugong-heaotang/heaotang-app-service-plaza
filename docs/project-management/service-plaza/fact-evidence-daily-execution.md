# 服务广场事实证据日执行清单

日期：2026-07-10

本文件用于把 `fact-evidence-submission-packet.md` 中的待提交事项转成每日可执行动作。当前不虚构事实证据，只登记下一轮提交顺序、完成条件、退回路径和门禁影响。事实证据提交顺序和依赖关系以 `fact-evidence-submission-control-board.md` 为总控。

## 一、执行原则

1. 先补平台事实，再补板块事实，再补 Handoff，最后补门禁和验收事实。
2. 每天只推进能形成事实字段的事项，不能用模板空字段替代事实。
3. 未完成提交包的 FE 项保持“待提交 / 未复核”。
4. 任一 FE 项进入“退回补充”，必须同步对应 ESC 阻塞。
5. FE 项全部未提交时，首次真实联调和第一阶段验收继续 No-Go。
