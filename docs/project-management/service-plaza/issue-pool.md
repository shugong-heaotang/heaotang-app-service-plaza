## 三、关闭规则

1. 问题关闭必须有证据编号。
2. 影响首次真实联调的 P0 问题关闭后，必须同步 `first-integration-go-checklist.md` 和 `phase-gate-status.md`。
3. 主链路阻塞未关闭或未明确延期前，不进入第一阶段验收。
4. 超过期限仍影响主链路的问题，进入 `blocker-escalation-decision-log.md`。
