# 服务广场第一轮问题关闭跟踪表

本文件用于跟踪第一轮联调前后产生的问题。问题未关闭或未明确延期处理前，不进入第一阶段验收。

## 一、关闭规则

1. 阻塞主链路的问题必须关闭后才能进入验收。
2. 不影响主链路的问题可以延期，但必须写明延期原因、补齐 Agent 和后续处理阶段。
3. 涉及架构边界、入口顺序、核心服务范围的问题必须由项目负责人裁决。
4. 涉及路由、权限、测试账号、测试数据的问题由平台 Agent 补齐关闭证据。
5. 涉及板块主动作、业务规则、验收标准的问题由板块 Agent 补齐确认结果。
