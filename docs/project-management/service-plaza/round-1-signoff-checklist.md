# 服务广场第一轮联调签核清单

本文件用于第一轮联调启动前的集中确认。当前项目采用项目负责人一人裁决和 agent 协同推进，签核不依赖多人回执，也不得把未形成证据的事项视为已完成。

## 一、签核目标

第一轮联调启动前，必须确认：

1. 项目负责人作为最终裁决人。
2. 规划 Agent、执行 Agent、文档 Agent、审计 Agent 分工明确。
3. 三大核心服务主动作可以作为第一阶段默认联调范围。
4. 正式页面或临时承接页路径明确。
5. 测试账号和测试数据准备证据明确。
6. 三大核心服务 Handoff 表单已提交或至少确认采用默认表单。

## 五、未签核时的默认推进方式

在签核未全部补齐前，可以继续做准备工作：

- 规划 Agent 保持第一轮范围和主动作口径。
- 执行 Agent 按建议路由准备临时承接页、账号和数据证据。
- 文档 Agent 按默认表单补齐 Handoff。
- 审计 Agent 复核门禁证据，不解除首次真实联调 No-Go。
- 不进入正式验收，不发布上线。
