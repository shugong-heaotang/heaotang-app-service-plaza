## 三、复核结论规则

| 复核结论 | 适用条件 | 后续动作 |
| --- | --- | --- |
| 未触发复核 | 尚无提交包或提交包为空 | 继续待提交 |
| 退回补充 | 提交包字段不完整、证据位置不可验证、回写文件不明确 | 回写 `fact-evidence-intake-review.md`，进入对应 ESC 阻塞 |
| 待门禁复核 | 提交包事实字段完整且目标文件已回写 | 更新 `fact-evidence-intake-review.md`，再由门禁清单判断 |
| 已失效 | 证据被新事实替代、范围变化或超过有效期 | 标记失效并要求重新提交 |
