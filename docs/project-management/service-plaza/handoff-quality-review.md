# 服务广场 Handoff 质量复核清单

本文件用于判断各板块 Handoff 是否可以被接收。Handoff 不是提交了就算完成，必须先按 `handoff-completion-action-pack.md` 明确补齐字段和退回条件，再按 `handoff-operating-mechanism.md` 完成提交、接收、退回和升级记录，并按 `handoff-fact-evidence-intake.md` 判断是否可进入 FE-HO 接收，最后通过质量复核后才能解除联调或验收门禁。

## 一、复核原则

1. Handoff 必须有提交人、接收人、交接阶段和提交时间。
2. Handoff 必须说明已完成、未完成、依赖、阻塞、下一步动作和确认人。
3. 开发给联调、联调给测试、测试给上线准备三个阶段必须补充对应阶段字段。
4. 信息不完整的 Handoff 不解除门禁，必须退回补充。
5. Partial Go 情况下，只复核进入联调或验收板块的 Handoff，未进入板块继续待提交。

## 二、阶段复核标准

| 交接阶段 | 必填字段 | 接收人 | 通过标准 |
| --- | --- | --- | --- |
| 需求给开发 | 接入卡、第一阶段主动作、页面方案、路由/返回路径、权限规则、接口或临时数据方案、正常/空/异常测试数据、验收责任和验收通过标准、提交人、提交时间、关联板块确认证据 | 平台 Agent | 能据此准备路由、权限、账号、数据 |

## 五、退回规则

| 缺失项 | 退回对象 | 退回原因 | 不退回风险 |
| --- | --- | --- | --- |
| 无责任边界或联系方式 | 板块 Agent、规划 Agent | 无法确认责任边界 | 问题无人关闭 |
| 无第一阶段主动作 | 板块 Agent | 无法判断联调路径 | 联调范围漂移 |
| 无页面或临时承接页方案 | 板块 Agent、平台 Agent | 无法准备路由 | 入口无法跳转 |
| 无权限规则 | 板块 Agent、平台 Agent | 无法验证登录和无权限状态 | 验收缺证据 |
| 无测试账号或测试数据 | 平台 Agent | 无法执行联调 | 联调记录不完整 |
| 无验收标准 | 板块 Agent、验收 Agent | 无法判断是否通过 | 验收争议 |
| 无已知问题 | 提交人 | 风险无法前置 | 问题关闭失真 |
