# 服务广场路由命名与临时承接页规格

本文件统一第一轮联调的路由命名、临时承接页要求和返回路径。正式技术实现由平台 Agent 补齐；未形成证据前，路由相关门禁保持 No-Go。路由、临时页和返回路径的接收入口见 `platform-route-account-data-evidence-intake.md`。

## 一、路由命名原则

1. 服务广场相关路由统一放在 `service` 或 `services` 命名空间下。
2. 三大核心服务不得混入首页、发现、我的页面命名空间。
3. 临时承接页路由必须能被正式页面平滑替换。
4. 路由命名应清晰表达板块，不使用模糊编号。
5. 路由变更必须同步 `integration-checklist.md` 和 `first-integration-go-checklist.md`。

## 三、临时承接页统一要求

临时承接页必须符合 ADR 0003。

| 要求 | 标准 |
| --- | --- |
| 标题 | 与服务广场入口名称一致 |
| 状态标识 | 明确标记为第一阶段联调承接页 |
| 主动作 | 至少提供一个可点击或可模拟提交的主动作 |
| 权限状态 | 能展示未登录、无权限、正常访问状态 |
| 数据状态 | 能展示正常、空状态、异常状态 |
| 返回路径 | 必须能返回服务广场 |
| 替换方式 | 后续正式页面可替换临时页，不影响服务广场入口 |

## 四、三大核心服务临时页内容

### 生命导航临时页

```text
页面标题：生命导航
状态标识：第一阶段联调承接页
建议主动作：提交导航申请 / 选择生命目标 / 提交基础测评
状态展示：提交成功、待处理、无权限、异常
返回路径：返回服务广场
```

### 俱乐部联盟临时页

```text
页面标题：俱乐部联盟
状态标识：第一阶段联调承接页
建议主动作：申请加入俱乐部 / 提交创建意向 / 查看俱乐部分类
状态展示：提交成功、审核中、无权限、异常
返回路径：返回服务广场
附属操作：管理中心入口可展示为受权限控制的附属按钮
```

### 健康大管家临时页

```text
页面标题：健康大管家
状态标识：第一阶段联调承接页
建议主动作：提交健康咨询 / 预约服务 / 查看健康档案入口
状态展示：提交成功、待处理、无权限、异常
返回路径：返回服务广场
```
