## 四、可接受证据类型

| 证据类型 | 可接受 | 说明 |
| --- | --- | --- |
| 本地台账记录 | 是 | 记录确认时间、确认人、确认结论和目标文件 |
| 日终复盘摘要 | 是 | 可作为单人确认后的摘要证据 |
| 企业微信或飞书消息截图 | 可选 | 仅当确实使用外部工具时保留时间、对象、标题或摘要 |
| 群消息链接或消息 ID | 可选 | 仅当确实使用外部群消息时记录链接、消息 ID 或群内定位方式 |
| 邮件记录 | 可选 | 仅当确实使用邮件时记录主题、时间、收件人和邮件编号 |
| 会议或公告记录 | 可选 | 仅当确实召开会议或发布公告时记录标题、时间和位置 |
| 口头说明 | 否 | 不能作为确认完成证据，必须补本地台账或摘要 |
| 未标明确认项的截图 | 否 | 不能证明对应确认项已完成 |

## 七、证据不足时的处理

| 场景 | 处理 |
| --- | --- |
| 已确认但无证据 | 不关闭 EVD-GAP-001，补本地台账记录或日终摘要 |
| 有证据但无确认项 | 证据不充分，补可识别确认项的证据 |
| 有确认证据但未回写确认表 | 当日补 `external-confirmation-tracker.md` |
| 有确认证据但未设置补齐动作 | 当日补 `reply-followup-cadence.md` |
| 确认项错误 | 重新确认，原证据标记为无效 |
