# 服务广场第一轮联调启动会确认包

本文件用于准备第一轮联调启动会材料。当前项目只有项目负责人一人参与，因此本文件不再作为多人会议外发通知，而是作为项目负责人本地确认和 agent 协同推进的启动口径。

启动会材料可以使用，但不得写成会议已经真实召开。是否进入首次真实联调，仍必须以台账证据和门禁文件为准。

## 一、启动会确认目标

| 目标 | 处理角色 | 输出 |
| --- | --- | --- |
| 确认第一轮范围 | 规划 Agent 起草，项目负责人裁决 | 第一轮只覆盖服务广场总入口、生命导航、俱乐部联盟、健康大管家 |
| 确认三大核心服务主动作 | 执行 Agent 补齐，审计 Agent 复核 | 主动作确认表待回写 |
| 确认正式页面或临时承接页策略 | 执行 Agent 补齐，项目负责人裁决 | 路由与临时承接页规格待回写 |
| 确认测试账号、测试数据和平台条件 | 执行 Agent 补齐，审计 Agent 复核 | 测试账号与数据清单待回写 |
| 确认 Handoff 提交和质量复核 | 文档 Agent 整理，审计 Agent 复核 | Handoff 表单和质量复核表待回写 |
| 判断是否允许进入首次真实联调 | 审计 Agent 给出证据结论，项目负责人裁决 | Go / Partial Go / No-Go |

## 三、本地确认议程

| 顺序 | 议题 | 处理方式 | 输出 |
| --- | --- | --- | --- |
| 1 | 确认第一轮目标和范围 | 规划 Agent 读取现有方案，项目负责人裁决 | 范围不扩展到常用服务 |
| 2 | 确认角色分工 | 使用规划 Agent、执行 Agent、文档 Agent、审计 Agent、项目负责人裁决 | 不再要求多人负责人到场 |
| 3 | 确认三大核心服务主动作 | 执行 Agent 按台账补齐，审计 Agent 复核 | 更新主动作确认表 |
| 4 | 确认路由、临时页、账号和数据 | 执行 Agent 形成证据，文档 Agent 回写 | 更新路由规格和测试清单 |
| 5 | 确认 Handoff 状态 | 文档 Agent 整理，审计 Agent 复核 | 更新 Handoff 表单和质量复核 |
| 6 | 做 Go / Partial Go / No-Go 判断 | 审计 Agent 对照门禁证据，项目负责人裁决 | 更新准备度报告和门禁状态 |
