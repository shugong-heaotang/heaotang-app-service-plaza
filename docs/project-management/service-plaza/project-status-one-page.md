## 已完成事实

- React/TypeScript/Vite 正式工程与 `/services`、三大核心服务路由已部署。
- 服务目录 `service-plaza.v1` 和动作目录 `service-plaza.action.v1` 已发布。
- 20 个页面动作由目录驱动；未交付能力禁用，俱乐部管理真实标为 preview。
- v1 认证信封、稳定机器码、原子验证码消费和 `club:manage` 已实现。
- API SDK 已统一超时、取消、严格信封、关联 ID 和安全重试。
- 三项创建接口强制幂等键；首次、重放、冲突、非法键和并发均已验证。
- 健康数据跨用户隔离通过。
- 接入方 Schema 自检和完整目录交叉校验工具已建立。
- 测试环境发布、备份和精确动作基线门禁通过；常规发布未轮换密钥。
- 远程验收运行：`service-plaza-uat-20260710-220412`。
- 业务变量 maker-checker 已在测试环境通过：同人审核 403、异人批准生成版本、旧单人写入口 409；真实价格仍未配置。
- AI 开发采用逐文件哈希检查单；并行工作项采用独立 `codex/` 分支和工作树，活动修改范围不得重叠。
- 近期 AI 编程事故教训已转化为生产权限隔离、不可信上下文、供应链和独立证据约束。
