# PDCAR registry scope correction 任务理解回执

我确认本任务是最高负责人明确批准的单路径权限纠正，不是PDCAR实施、Project Brain实施或普通registry生命周期变更。

我只删除PDCAR formal implementation work item的共享registry allowed path，保持其`active`和其余14项路径及所有字段不变。纠正候选、提交、自测和Handoff都不等于authority；独立Go和受控集成前不得push。

我不会新增第二个active registry owner，不会修改其他work item，不会创建PDCAR正式工作树，不会修复M2 runtime，也不会启用真实数据、凭据、网络、部署、timer或production。

纠正进入authority后，Project Brain获得的只是另立M2 remediation activation的前置条件；它不自动获得runtime修复或集成授权。PDCAR后续closeout必须另行登记。
