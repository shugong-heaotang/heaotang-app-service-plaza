## 二、任务目标与接口基线

登录用户从 `/services/club-alliance?category=自建俱乐部` 浏览后端权威筛选的 `type=standard` 俱乐部，幂等提交加入申请，查看本人申请状态；俱乐部管理者只审核本俱乐部 pending 申请，批准时成员写入与申请状态在同一事务中成功。

| 项目 | 当前基线 |
|---|---|
| 服务 ID | `club-alliance` |
| 返回路径 | `/services` |
| 自建列表/详情 | `GET /api/v1/clubs/search?type=standard`、`GET /api/v1/clubs/:id`；禁止用 `/clubs` 做前端伪筛选 |
| 加入申请 | `POST /api/v1/clubs/:id/join`，必须携带 `Idempotency-Key` |
| 管理者待审 | `GET /api/v1/clubs/:id/join-applications` |
| 审核 | `PUT /api/v1/clubs/:id/join-applications/:aid/review`；当前缺幂等，M2 前必须关闭 |
| 本人状态 | M1 必须提交精确路径、分页/状态/信封/本人归属/跨用户/错误码并获平台批准 |
| 自建筛选 | 已冻结 `/clubs/search?type=standard`；M1 补混合类型只返回 standard 的正向回归 |

M2 前平台必须关闭：本人状态接口；审核 `Idempotency-Key` 的首次/重放/异载荷/并发相反决定；standard 错误依赖 family 容量配置；普通用户与跨俱乐部越权；成员/积分/状态/commit 失败回滚；稳定 400/403/404/409 机器错误矩阵。任一未关闭均为 M2 No-Go。

本切片不做家庭/公益俱乐部、友联体、会费、支付、提现、分账、付费套餐和完整管理中心。页面、适配器和测试禁止调用 fee/account/paid-service/payment/withdraw 路由。任何价格、比例、名额或有效期必须来自经双人审核的版本化配置，未配置时失败关闭；请求体 price 和旧收入记账不得进入本切片。

`club-manage` 动作保持 preview。模块可直测管理视图，但不得自行把动作改为 active；正式服务广场管理入口升级由平台独立工作项处理。
