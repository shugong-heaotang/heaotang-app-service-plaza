## M0 非目标和禁止边界

- 不实现前端、后端、API 路由、数据库迁移或真实运行时。
- 不触达真实会员，不发送消息或验证码。
- 不执行支付、退款、结算、分账或任何真实资金动作。
- 不部署测试环境或生产环境，不修改生产配置和密钥。
