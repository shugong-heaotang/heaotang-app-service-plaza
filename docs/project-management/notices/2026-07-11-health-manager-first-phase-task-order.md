## 二、任务目标与固定接口

登录用户从 `/services/health-manager` 提交个人健康咨询，通过本人历史列表查看 `pending` 等状态，并返回 `/services`。

| 项目 | 标准 |
|---|---|
| 服务 ID | `health-manager` |
| 创建咨询 | `POST /api/v1/health/consultations` |
| 本人历史 | `GET /api/v1/health/consultations?page=<n>&size=<n>` |
| 请求字段 | `patient_name`、`symptoms` |
| 身份 | 平台共享 JWT；用户 ID 只能来自会话 |
| 幂等 | POST 必须携带 `Idempotency-Key` |
| 初始状态 | `pending` |
| 隐私 | 只能读取本人记录；咨询正文不写结构化日志、不发送 AI |

当前运行事实：本人列表按 `id DESC`，page 最小 1，size 为 1..100，非法值回退 page=1/size=20，空列表为 `items=[]`。POST 的首次/重放/冲突语义固定为 201、200 加 `Idempotency-Replayed: true`、409 `IDEMPOTENCY_KEY_REUSED`；前端复用共享 `executeWithMeta`，不得直接调用 `fetch`。

M2 前平台必须关闭：字段 trim/必填/最大长度；POST/GET DTO 与稳定错误矩阵；GET `Cache-Control: no-store`；咨询正文不进入日志/遥测/证据的专项验证；`app/src/modules/health-manager` 的平台路由挂载工作项。任一未关闭均为 M2 No-Go。

本切片不做诊断、处方、急救替代、AI 建议、预约、收费、报告生成、家庭共享和医生处置闭环。测试环境固定提示：“本服务仅接收健康咨询，不构成诊断或处方，也不替代急救；如有紧急情况，请立即呼叫 120 或前往医疗机构。”正式生产法律文本仍需独立确认，不得自行声称医疗效果。
