# 公益创办审批与区域管理中心需求冻结

## 不可替代的业务语义

- 公益俱乐部不是普通创建类型。唯一识别组合为 `type=standard + category=charity`。
- 普通 `/api/v1/clubs` 创建入口必须拒绝该组合，稳定错误码为 `PUBLIC_WELFARE_APPLICATION_REQUIRED`。
- 申请人先提交使命、资格、资源、治理、风险及完整 PDCAR；提交本身不得创建俱乐部。
- 俱乐部联盟管理员批准后，必须在同一事务中创建 active 公益俱乐部、写入 owner 成员关系、回写申请和审计；失败时全部回滚。
- 申请人不能审核自己的公益创办或区域岗位申请；所有写操作使用 Idempotency-Key。
- 区域主任/副主任批准后，必须写入精确到省、市、区县的真实角色授权，而不是只改变申请状态。
- 区域管理中心和公益服务中心是两种中心类型；公众可按省、市、区县、名称或地址查找，联系方式只返回脱敏值。

## 三个页面入口

1. 公益俱乐部：展示申请制说明、完整创办表单和本人申请状态。
2. 俱乐部联盟：展示区域管理中心页面、中心查找及主任/副主任申请。
3. 管理中心：仅授权用户查看并审批两类申请，审核意见必填。
