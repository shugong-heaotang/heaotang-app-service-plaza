# CA-UF M0 需求基线

## 目标

在业务编码之前冻结五类治理事实：可追溯编号、分层审批、俱乐部授权的代表权、版本化章程、分空间交流治理。

## 必须满足

1. 编号由服务端在权威事件后分配；不同对象使用独立命名空间；永久不复用，不嵌入可变属性。
2. 审批覆盖组织资格、成员俱乐部确认、联盟治理审查和条件性风险审查；申请人与终审人分离。
3. 代表权只能来自成员俱乐部的有范围、有期限、可撤销授权；普通会员不天然拥有联盟表决权。
4. 章程必须版本化、经成员俱乐部确认；生效版本不可原地修改；缺少有效章程时禁止激活和治理写入。
5. 交流按公告、治理议事、会员协作、公开信息分空间；群组有独立编号；私信默认关闭并需双方明确同意；治理处分可申诉且留审计证据。
6. 人数、时限、票数、容量与保留期只引用版本化配置键；缺失时失败关闭。

## 明确不做

本轮不实现数据库、接口、前端、即时通信、部署或真实数据；会费、募资、支付、提现、退款、订阅全部禁止。
