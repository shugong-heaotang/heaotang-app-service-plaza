# H2-M0 决策

## CMH-D001 双层首页

Accepted：会员事实优先，联盟分类探索在后。H1 四入口继续作为探索层，不删除、不复制上游动作真相源。

## CMH-D002 友联体语义

Accepted：友联体保持 `club-federation` 关系入口，不作为第四种 ClubType；展示文案必须避免与公益/自建/家庭三类下属俱乐部混淆。

## CMH-D003 聚合缺口失败关闭

Accepted：会员摘要、待办、本人活动、动态在权威接口完成前保持 gap。M1 只允许 fixtures 证明页面状态，运行时不得 mock；M2 必须独立关闭接口与本人授权缺口。

## CMH-D004 局部降级

Accepted：关键我的俱乐部失败阻断会员工作台；待办和活动失败显示局部错误；动态失败可隐藏。catch 后空数组不等于成功。
