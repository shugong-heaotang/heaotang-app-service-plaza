# 健康大管家 R5-C1 咨询、第二意见与疑难病例协同合同冻结

## 结论

R5-C1 只冻结离线、合成、不可执行的咨询、第二意见、疑难病例专家定向征集与多学科会诊合同。健康大管家只负责整理经授权资料、生成非诊断性结构化摘要、识别缺失、匹配已核验专家候选并准备人工复核包；医生集团医疗质量人员负责初审和风险分流，正式诊疗只能由具备相应资质的医疗机构承接。

## 结构化转介与人工初审

- 转介包必须记录申请类型、申请人引用与合法权限、授权引用和状态、主要诉求、来源资料引用、来源与版本、缺失资料、责任协调人、提交时间和包版本。
- 申请人仅允许会员本人或已核验合法代理人；授权缺失、过期、来源不明、版本或责任人缺失时失败关闭。
- AI 输出仅为结构化摘要和缺失清单，不构成诊断，也不能批准初审。
- 医生集团医疗质量人员必须完成人工初审；急症、专业风险或不适宜线上处理时停止线上流程并转线下合规医疗机构，资料不足时保持 hold 并补充资料。

## 专家征集、主责医生与第二意见

专家征集只面向已核验专家池定向发起，不设公开病例板、抢单或竞价。专家必须通过身份、医师资格、执业证书、执业范围、服务方式和利益冲突披露/复核门禁。每个正式承接必须可追踪主责医生或 MDT 成员身份、角色、执业范围和合规医疗机构。

第二意见要求独立复核人及其资质/范围可验证；原意见不可覆盖，第二意见作为独立版本保存，分歧原样保留并交人工负责。AI 不得合并、替换意见或选择最终医疗结论。

## 审计、费用与禁止模式

申请、授权、摘要、人工初审、分流、专家邀请、冲突复核、接受/拒绝、主责医生或 MDT 指派、意见、后续安排和服务关系变化均需记录事件、责任主体、时间、来源、版本、政策版本和关联引用。原始来源与意见不可变，纠错追加新版本。本切片只定义费用状态、政策引用和复核 owner，不授权真实金额、收费或支付。

禁止公开身份或完整病历、公开抢单、医生竞价、治愈悬赏、结果付费、疗效承诺、未经核验专家、非医疗机构诊断/治疗以及商业因素越过安全顺序。
