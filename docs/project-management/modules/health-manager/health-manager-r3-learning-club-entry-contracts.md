# 健康大管家 R3-C1 健康学习与健康俱乐部入口合同冻结

## 结论

R3-C1 只冻结离线、合成、不可执行的跨模块入口合同。健康馆可以展示会员已授权的最小学习/俱乐部摘要并跳转到权威模块，但学习资源、路径、笔记、进度属于学习广场，俱乐部成员关系、活动、反馈与内容治理属于俱乐部联盟。

## 最小摘要与权威跳转

- 学习摘要只包含 `currently_learning`、`recently_completed`、`recommended_learning` 和 `resource_reference`。
- 俱乐部摘要只包含 `visible_club_card`、`member_join_status`、`join_mode` 和 `safety_notice`。
- 摘要读取必须同时具备会员授权、数据最小化、权威来源和来源版本；字段不在 allowlist 时失败关闭。
- 跳转只使用服务目录已登记的 `/services/learning-plaza` 和 `/services/club-alliance`；权威模块保留全部写入所有权。

## 会员确认回传

学习完成或俱乐部活动/反馈不得自动进入健康档案。只有会员明确确认，并保留来源权威、来源引用、来源版本、确认记录、责任人及目标复核状态后，才能形成 `health_management_record_candidate`。候选不得自动升级为医疗记录，也不能把学习完成等同于健康改善。

## 隔离与 AI 边界

首期不共享数据库表，不复制学习或俱乐部权威状态，健康大管家不得修改学习进度或俱乐部成员关系，俱乐部管理员无独立授权不得读取完整健康档案。AI 仅可整理已授权合成摘要、识别缺失、匹配已审核候选并解释不确定性；不得诊断、开药、改药、冒充医生、自动确认回传或关闭专业/紧急风险。

## 验收范围

`test_health_r3_learning_club_entry.py` 提供 Schema、基线与 15 个负例门禁，覆盖需求哈希、摘要超量、缺少授权、伪造路由、跨模块直写、权威夺取、自动/未确认回传、追踪字段缺失、完整健康档案暴露、AI 医疗越界、会签擅升、真实数据授权和敏感模式。
