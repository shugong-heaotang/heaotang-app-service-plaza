# 健康大管家 R4-C1 医生目录与受约束推荐合同冻结

## 结论

R4-C1 只冻结离线、合成、不可执行的医生目录和受约束推荐合同。医生集团治理目录是资质、执业、专科、质量与退出状态的权威来源；健康大管家只能读取已核验摘要、形成可解释候选并请求人工复核，不能创建或修改医生资质、执业范围和专业标签。

## 硬门禁与排序

- 进入候选池必须同时通过身份、医师资格、执业证书、执业机构、执业范围、诊疗科目、服务方式、可接诊状态和质量状态门禁。
- 缺失、未核验、过期、撤销、暂停、来源冲突、执业范围不匹配、投诉暂停或退出均默认拒绝。
- 推荐顺序固定为法定资质与执业关系、专业匹配、线上/线下安全分流、质量治理、培训治理、可接诊性和会员明确偏好。
- 和奥堂培训只可在专业匹配与安全等级相同、全部硬门禁通过时作为并列因素；不得替代法定资质或执业范围。

## 商业中立、解释与退出

付费、竞价、佣金、广告投入、机构商业关系和结果费用不得进入医疗安全或专业匹配排序。本切片不授权公开医生排名、真实价格、收费或支付。每个候选必须解释匹配标签、资质/执业证据、质量依据、服务方式、不确定性、人工复核状态和政策版本。

紧急或专业风险、资质来源冲突、边界执业范围、质量标记、投诉暂停和不适宜线上处理必须转人工。退出或暂停后必须移出候选池、停止新推荐、保留审计并通知治理 owner；重新进入需重新核验和人工批准。

## AI 边界

AI 只可整理已授权的合成需求、识别缺失、从已核验池匹配候选、解释原因与不确定性、标记风险并准备人工复核包。AI 不得诊断、开药、改药、冒充医生、承诺疗效、创建资质/专科标签、绕过硬门禁、因付费改变排序或独立关闭专业/紧急风险。
