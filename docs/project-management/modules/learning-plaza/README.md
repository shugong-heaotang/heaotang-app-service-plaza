# 学习广场

学习广场是独立的通用学习平台。它可以接收生命导航的学习目标并返回成长事件，但不属于生命导航；Nova 学习助手是内部应用，Nova AI Engine 是共享连接能力。当前检查点为 M0-R2，只交付 v3.0 需求、版本化架构合同、确定性 fixtures 和离线验证，不包含正式页面、API、数据库、支付、部署或上线。

## 核心板块

1. 内部应用：课程、读书、考试认证、Nova 学习助手、学习记录、成长档案、内容审核中心。
2. 连接能力：知识库、直播板块、Nova AI Engine、统一身份和订单支付。
3. 外部项目：生命导航、俱乐部联盟、会员成长档案和保障商城。
4. 内容治理：AI 初审与人工终审可独立开关，开关变更必须双人审批，任何发布路径保留审计。
5. 内容商业：知识类目录归学习广场，非知识类目录归保障商城。
6. 学习事实：学习广场保存权威事实，通过幂等事件投影到外部成长系统。

## M0 边界

- `execution.mode=mock-only`、`environment=non-production`。
- 跨项目端口在真实 owner/version 未确认前为 `provisional`，调用必须失败关闭。
- 旧 M0 保留为历史证据，M0-R2 由 v3.0 需求和 ADR 0001 取代其项目层级结论。
- 可执行入口：`python -X utf8 contracts/modules/learning-plaza/m0-r2/validate_learning_plaza_m0_r2.py`。
