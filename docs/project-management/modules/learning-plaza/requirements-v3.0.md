# 学习广场独立项目需求 v3.0

日期：2026-07-13
状态：M0-R2 冻结候选，等待独立验收

## 一、项目定位

学习广场是独立的通用学习平台，不属于 Nova，也不专属于生命导航。生命导航包含“学习”板块，因此可把成长目标传给学习广场，并接收学习成果事件；这种关联不改变双方的数据所有权。

Nova 分为两层：`Nova 学习助手`是学习广场内部应用；`Nova AI Engine`是可复用的平台能力。历史 Nova 仓库中的学习广场代码仅作参考，不作为学习广场运行时归属。

## 二、应用与连接边界

学习广场内部应用：课程、读书、考试与认证、Nova 学习助手、学习记录、成长档案、内容审核中心。

连接但不由学习广场整体拥有的能力：知识库、直播板块、Nova AI Engine、统一身份、统一订单与支付。知识库与 Nova 紧密协作；直播保持独立板块，通过版本化接口接入。

外部关联项目：生命导航、俱乐部联盟、会员成长档案、保障商城。俱乐部首先是学习组织者，不因组织学习而自动取得原始内容所有权。

## 三、内容、审核与商业边界

内容版权、发布责任和学习组织权分别记录。学习广场审核委员会负责最终审核治理，默认流程为 AI 初审后人工终审；AI 审核与人工审核均可独立开关。

四种模式：双开时人工终审；仅 AI 开时 AI 通过即可发布；仅人工开时直接人工审核；双关时仅获授权发布者可直发，仍强制保留发布者、来源、版权、版本、时间、变更、下架和审计记录。审核开关属于关键配置，必须版本化并双人审批。

知识类商品和权益由学习广场拥有目录与履约语义；非知识类商品由保障商城拥有。可以复用统一订单支付能力，但商城不能成为知识目录的事实源。

## 四、Nova 学习助手

允许：推荐课程和学习资料、答疑、解释、制定学习计划、总结复习、考试准备和下一步建议。回答必须基于当前用户可见资料并提供引用。

禁止：代用户报名、购买、完成课程、伪造学习记录、代考、发证、绕过审核或直接修改外部项目数据。

## 五、学习事实与成长投影

学习广场是学习进度、完成事实和证据的权威事实源。任何学到的内容都可以形成版本化成长事件；生命导航、俱乐部会员成长档案和会员成长档案分别消费事件并形成投影，不复制或反向修改学习事实。

## 六、首阶段实施顺序

1. 建立独立项目骨架：应用注册表、路由边界、权限、数据所有权、审核策略和连接器位置。
2. 立即打通课程闭环：提交课程 -> 审核 -> 发布 -> Nova 推荐 -> 用户开始学习 -> 记录进度 -> 完成 -> 生成成长事件 -> 外部投影确认。
3. 再扩展读书、考试认证、直播接入、俱乐部共学和知识商品交易。

M0-R2 只冻结合同并离线验证。共享前端、后端、数据库、支付、部署、真实用户和生产均需单独授权。
