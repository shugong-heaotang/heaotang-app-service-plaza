# ADR 0001：学习广场采用独立项目与内部应用架构

- 状态：Accepted candidate
- 日期：2026-07-13

## 背景

旧 M0 把学习广场称为生命导航的学习执行层，并把 Nova 整体建模为外部端口；Nova 参考仓库又直接承载学习广场服务，三种表述会把项目、应用和共享引擎混成一个运行时所有者。

## 决策

学习广场是独立通用学习平台。课程、读书、考试认证、Nova 学习助手、学习记录、成长档案和审核中心是其内部应用；知识库、直播和 Nova AI Engine 通过版本化连接器接入；生命导航、俱乐部联盟、会员成长档案和保障商城是外部关联项目。学习事实只由学习广场持有，外部系统消费版本化事件形成投影。

第一阶段先建立完整应用骨架，随后立即完成课程学习闭环，不等待所有应用都实现。

## 前提

- Nova AI Engine 可以与 Nova 学习助手分层；若引擎无法提供稳定接口，需重新评估连接器。
- 知识库与直播存在独立事实源；若未来并入学习广场，需要新 ADR 和数据迁移计划。
- 外部成长系统可以消费幂等版本化事件；若只能共享数据库，本决策不得降级为直接写表。
- 审核开关能进入平台双人审批配置；若不能，双关直发模式保持不可用。

## 后果

项目所有权清晰，Nova 不再承载学习广场运行时；代价是需要独立路由、应用注册表、连接器和事件投影协议。旧 M0 由本 ADR 与 v3.0 合同取代，但作为历史证据保留。
