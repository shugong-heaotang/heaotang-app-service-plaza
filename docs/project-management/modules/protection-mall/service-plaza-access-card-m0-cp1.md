## 页面状态要求

- 未登录：进入统一登录/承接状态，不泄露会员或订单数据。
- 无权限：稳定错误码和无权限状态；前端预检不能替代服务端授权。
- 维护中：入口失败关闭并保留返回服务广场路径。
- 空数据：显示“暂时没有可购买的商品或服务”。
- 异常：显示“商城服务暂时不可用，请稍后重试”，并保留 request ID。

## M0 会签请求

请平台集成负责人确认入口冻结值、共享会话、返回路径、遥测名称，以及 `mall.api.v1` 是否可以作为商城内部业务契约主版本。生命周期在 M0 保持 `planned`。
