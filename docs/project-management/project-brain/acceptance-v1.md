# 和奥堂 Project Brain v1 验收矩阵

| 编号 | 验收项 | 通过标准 | 证据 |
|---|---|---|---|
| PB-A01 | 唯一入口 | 根入口能定位全部事实类别且不复制动态状态 | 链接审计 |
| PB-A02 | 模式验证 | 四类事实文件全部符合 Schema | 自动测试日志 |
| PB-A03 | 路径安全 | 外部绝对路径和 `..` 越界被拒绝 | 安全测试 |
| PB-A04 | 权威唯一 | 重复权威来源触发 error | 冲突夹具测试 |
| PB-A05 | 状态新鲜度 | 过期活动项触发 error 或 warning，规则有明确期限 | 过期夹具测试 |
| PB-A06 | 完成真实性 | 缺独立验收或集成证据的 integrated 被拒绝 | 负向测试 |
| PB-A07 | 角色分离 | 高风险项同人开发、复核、批准被拒绝 | 负向测试 |
| PB-A08 | 未知处理 | 缺失事实显示 Unknown，不显示 Go | 单元测试、页面截图 |
| PB-A09 | 只读界面 | 页面无修改、批准、部署、删除动作 | DOM 测试、UAT |
| PB-A10 | 来源追溯 | 每个状态卡均能看到来源和更新时间 | DOM 测试 |
| PB-A11 | 现有路由回归 | 现有服务广场和三大模块路由测试不退化 | 全量前端测试 |
| PB-A12 | 响应式 | 360px 与桌面宽度无横向溢出，关键信息可读 | 浏览器证据 |
| PB-A13 | 敏感数据 | 快照不包含令牌、密码、手机号、健康明细或支付数据 | 安全扫描 |
| PB-A14 | 构建 | TypeScript、Vite 构建通过 | 构建日志 |
| PB-A15 | 编码 | 仓库 UTF-8 门禁通过 | 编码门禁日志 |
| PB-A16 | 交接 | 实施记录、Handoff、风险和下一授权齐全 | 文件审计 |

## Go 条件

PB-A01 至 PB-A16 全部通过，且独立验收者给出 Go，第一版方可进入集成。任何安全、权限、真实数据或证据真实性失败均为 No-Go。
