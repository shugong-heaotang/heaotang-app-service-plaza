# 和奥堂业务变量标准 v1

价格、额度、比例、会员权益、有效期、排序和运营开关等会变化的因素，必须通过稳定配置键读取，不得写入业务硬代码。

## 金额规则

- 使用整数最小货币单位，例如 80 元表示 `8000` 分；禁止 `float`。
- 同时记录 ISO 4217 币种，本阶段人民币为 `CNY`。
- 会员价格只登记稳定键，不设置猜测默认值。
- 未配置时接口返回 `configured:false`；页面显示待配置，收费接口必须拒绝创建订单。
- 支付时把采用的变量版本写入订单快照，后续改价不得改变既有订单。

## 变更规则

- 录入人只生成 pending 提案；不同管理员审核批准后才生成版本，同一人审核由服务端拒绝。
- 录入和审核都必须有修改原因、`X-Request-ID` 和 `Idempotency-Key`。
- 新值按版本追加，不覆盖历史；支持 RFC3339 未来生效时间。
- 同一幂等键同载荷返回原版本，不同载荷返回 409。
- 查询按业务发生时间解析当时有效版本，审计可追溯修改人、原因和请求。

机器基线：`contracts/foundation/business-variables.v1.json`。后端实现：`internal/businessconfig`。首批定义会员月费、家庭俱乐部套餐价格和成员容量；具体收费价格由后台双人审批配置决定，不能由代码猜测。
