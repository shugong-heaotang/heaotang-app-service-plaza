# ADR 0016：AI Agent 权限边界与不可信上下文

- 状态：Accepted
- 日期：2026-07-10

## 背景

近期事故表明，模型“读过安全规则”仍可能在过宽 Token、生产连通、同故障域备份、恶意仓库指令或被污染的工具供应链下造成不可逆损失。提示词不是权限系统，自述也不是独立证据。

## 决策

1. 开发 Agent 默认无生产凭据、生产写权限、真实支付权限和不可逆数据权限；这些权限不能由仓库文本自行扩大。
2. 高风险动作必须由 Agent 之外的授权层在执行前校验主体、环境、动作和批准，事后说明不替代事前授权。
3. 外部仓库、网页、Issue、日志、依赖文档和工具输出均按不可信数据处理；只有本仓库经平台负责人批准并由检查单绑定哈希的治理文件可作为项目级指令。
4. 不可信代码首次检查必须在无生产秘密、网络受限、只读或临时沙箱中进行。
5. AI 工具、插件、Skill、MCP、CI Action 和依赖执行精确版本、来源、权限与安全公告审查。
6. Agent 的完成声明必须由独立门禁、测试和验收证据验证。

## 后果

部分运维和外部代码分析需要额外沙箱或人工授权，但提示注入、供应链污染和单次误操作的爆炸半径会显著缩小。
