# ADR 0014：AI 开发起飞检查单

- 状态：Accepted
- 日期：2026-07-10

## 背景

README 中列出必读文件仍无法回答“本次 Agent 实际确认过哪些文件”。治理文件变化后，历史口头确认也会失效。

## 决策

每个非平凡实现切片必须建立 `development-checklist.v1`。清单逐项记录治理文件路径、读取时的 SHA-256、明确勾选时间和执行者；所有项目完成后才能写入固定声明并标记 completed。实现记录必须引用同一 `record_id` 的清单。任一治理文件内容变化会使旧哈希失效，门禁要求重新阅读和确认。

清单证明的是可审计的阅读确认动作，不单独证明语义理解。是否正确落实仍由契约、测试、代码审查、验收证据和 Handoff 验证。

## 后果

新 Agent 的启动动作可被其他 Agent 或人工复核；代价是每个切片增加一次显式阅读确认，治理文件变化会触发重读。
