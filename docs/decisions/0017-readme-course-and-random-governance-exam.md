# ADR 0017：README 课程与随机治理考试

- 状态：Accepted
- 日期：2026-07-10

## 背景

文件级起飞检查单能够证明 Agent 确认过哪些治理输入，但不能检验它能否把规则应用到真实开发场景。项目负责人要求把 README 和关联治理文件作为一门必修课，开发前随机考试；未通过必须重读并重考。

## 决策

1. 起飞检查单完成后、修改业务代码前，必须参加 `governance-exam.v1` 随机考试。
2. 每次从版本化题库随机抽取 8 道场景题，及格分 100；任一题错误即失败。
3. 试卷绑定题库、必读清单和起飞检查单 SHA-256。开考时必须与当前文件一致；完成后作为不可修改的历史快照保留。
4. 失败试卷不可改成通过；保留错误答案、分数和应重读来源，下一次使用递增 attempt_number 新建随机试卷。
5. 实施记录引用与自身 `record_id` 相同且状态为 passed 的试卷，否则总门禁失败。
6. 本地考试是开卷自测，答案对 Agent 可见，因此只证明回答与当前规则一致，不单独证明深层理解；代码、测试和验收仍是独立证据。
7. 治理文件变化后，旧成绩仍证明原任务在当时通过，但不得授权新任务；新任务必须生成当前检查单并重新考试。题库内容变化必须发布新版本，不得原地修改已用于评分的答案。

## 后果

每个开发切片增加一次短考试，但可以在动手前发现对根因、权限、配置、协作和证据规则的误解。需要防止查答案时，应把出题与答案迁移到独立监考服务端。
